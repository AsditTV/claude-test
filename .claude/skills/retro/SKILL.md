# Retro

1. Relire la session : erreurs répétées, corrections de l'utilisateur, préférences exprimées, commandes utiles découvertes.
2. Proposer **3 règles maximum**, chacune :
   - une ligne, impérative, vérifiable ;
   - avec la raison en une phrase (l'incident de la session qui la justifie) ;
   - le fichier cible : `CLAUDE.md` du projet ou `~/.claude/CLAUDE.md`.
3. Ne rien proposer qui duplique une règle existante (lire le CLAUDE.md d'abord).
4. **Ne jamais modifier CLAUDE.md sans validation explicite** de l'utilisateur, règle par règle. Sans réponse claire : ne rien écrire.
5. Si rien ne mérite une règle, le dire. Zéro règle vaut mieux qu'une règle inutile.
